# RL / OPD / Agentic RL 面试刷题库

题库按共同的 Q001–Q224 编号合并两份用户提供的资料：

- `RL_OPD_Agentic_RL_面试题库_完整版.md`：题目、简短回答和追问落点；
- `RL_OPD_Agentic_RL_面试问题与参考答案.docx`：同一题号的长篇解释与例子。

合并结果为 **224 道题**，前 104 道基础、后 120 道进阶。Q015、Q026、Q061、Q127、Q136、Q169、Q175、Q193、Q200 的提问措辞不完全一致，页面保留两份原始问法。所有题目由来源内容提取，并非逐题经过公式和外部文献校勘；尤其 Word 原文中的部分公式在文本提取后不完整，应参照原文/论文复核。

## 使用

网页版先显示题目，独立作答后点击“查看参考答案”。可以在详细解释和速答要点之间切换，并阅读追问，之后按照真实掌握程度自评。自评用于筛出错题与安排复习，不是 AI 自动打分。

自评档位：再练（当天）、还不熟练（次日）、基本掌握（3/7/14/30/60 天）、非常熟练（7/14/30/60/90 天）。它们是教学默认间隔，不代表经过个人实验优化。

所有草稿、收藏、笔记及复习状态仅保存在本地 `localStorage`；“导出记录”可以备份 JSON，换设备可以导入。

## 数据结构

```text
quiz/data/questions.json
         +
quiz/template.html, style.css, app.js
         |
scripts/build_quiz.py
         |
dist/quiz/index.html
```

`questions.json` 是唯一正式题目源文件，存储每题的编号、原始问法、速答、详细解释、追问、领域、难度和关联课程 Day。关联课程是辅助参考，未发布的课程链接可能暂时回到首页已发布课程。

原始两份文件不直接发布到网站；结构化题目内容为可公开教学材料，请勿在这里附加个人作答、公司信息或敏感技术数据。

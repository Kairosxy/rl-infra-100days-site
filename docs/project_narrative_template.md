# 项目决策与面试陈述模板

这是从旧项目的空白项目叙事模板整理出的公开练习材料，不是个人项目记录，也不代表已有工程成果。

复制本模板到个人笔记后填写。未经确认可公开的内容不应提交到网站仓库。

## 项目名称

### 问题

系统遇到了什么可明确描述的问题？它影响了正确性、吞吐、尾延迟、资源消耗或可靠性中的哪一项？

### 约束

哪些条件不能改变？数据分组、策略版本、共享 GPU、响应长度和恢复边界等是否影响方案？

### 备选方案与选择

考虑过什么替代方案？为什么采用当前设计？说明必要的算法等待与外层实现引入的等待。

### 证据

给出可公开复现的实验配置、日志摘要、测量与负例。没有实测时注明“尚未测量”。

### 代价

该方案在实现复杂度、额外计算、显存、通信、调度和故障恢复方面付出什么代价？

### 两分钟面试陈述

按照“问题 → 约束 → 方案 → 证据 → 代价”总结，准备解释各项指标的定义、基线和实验限制。

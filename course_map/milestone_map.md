## Day 10 的验收项

- Loss 和 Gradient 都是有限数值。
- Mask 与 Token 对齐正确；至少一个故意制造的错位会被测试捕获。
- Policy Version 可以追踪。
- Reward 按稳定 ID 关联，不依赖列表顺序。
- 至少一个训练指标有可解释的变化；不要求在随机小模型上达到某个预设成绩。
- Checkpoint 能保存和恢复 Policy、Optimizer State、训练步数和版本号。
- 恢复后的执行通过明确的状态一致性测试。

## 评分原则

每个检查点分别检查概念解释、数学推导、实现与测试、技术表达。没有学习者答案时状态为“尚未评估”。性能实验必须标明硬件、软件版本、配置和原始结果；理论估算不能代替测量。

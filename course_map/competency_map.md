# 能力地图

这张表用于检查课程覆盖范围，不用于提前判断学习者已掌握哪些内容。每项能力都需要通过解释、实现或实验验证。

| 能力域 | 必须能回答的问题 | 可验证的证据 |
|---|---|---|
| RL 数学 | Policy Gradient、GAE、PPO、GRPO 各自优化什么？ | 手推公式；对小张量验证梯度 |
| 数据语义 | Trajectory、Reward、Mask、Logprob 如何保持对齐？ | 数据契约与负例测试 |
| GPU 性能 | 时间花在算力、带宽、Launch 还是通信？ | Roofline 估算、Profiler trace |
| 模型并行 | TP/PP/DP/EP/CP 各自切分什么，代价是什么？ | Shape 推导与拓扑图 |
| 推理系统 | Prefill、Decode、KV Cache 如何影响延迟和吞吐？ | 容量估算与可复现实验 |
| Agentic RL | 多轮工具交互如何形成可训练轨迹？ | Token/工具事件对齐测试 |
| 异步训练 | 哪些等待是必要依赖，哪些是批次屏障？ | 时序图、队列指标、对照实验 |
| 一致性 | Behavior、Old、Current Policy 的概率语义是什么？ | Logprob 对照与版本审计 |
| 可靠性 | 崩溃后如何恢复且不重复消费或错配数据？ | 故障注入、恢复测试 |
| 面试表达 | 能否说清问题、证据、决策、代价和结果？ | 项目陈述与追问记录 |

## 已有经验如何进入课程

课程会用公开、通用的工程场景连接 VERL、SGLang、Megatron、Ray、FP8、Partial Rollout 和 TransferQueue。已有经验用于提出更贴近实际的问题，但不能代替基础解释。

没有代码、日志或实验结果作为证据时，不把某项实现描述为已验证成功；也不把公司内部实现细节写入公开作品集。

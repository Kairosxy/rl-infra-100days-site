# Day 05 · 四条回答，什么时候没有学习信号？

同一个 Prompt 采了四条 Response。

**第一眼判断：**

```text
组 A: [1, 0, 1, 0]
组 B: [1, 1, 1, 1]
```

如果使用组内标准化 Reward 构造 Advantage，**哪一组能区分好坏回答？**

**答案：A。** A 的 Advantage 约为 **[+1,−1,+1,−1]**。B 虽然全部正确，但组内没有差异；在带正数 ε 的标准化规则下，B 的相对 Advantage 全为零。

试着不看答案，用一句话解释：

> GRPO 的这一类 Advantage 是在同一个 Prompt 的回答之间作比较。奖励全相同，就没有相对方向；并不代表模型所有训练项都没信号。

**再判断一个工程情况：** 计划采四条，第三条刚返回时，已经收到 `[1,0,1]`。能否先当成原来那个四样本 Group？

**不能直接这么做。** 三样本统计的 Advantage 约为 **[0.707,−1.414,0.707]**，与四样本时不同。改变组大小就改变了比较对象，不能当成同一目标的“提前结果”。

需要深入理解组内均值包含自身 Reward 造成的偏差时，再读 [讲义中的二样本反例](lesson.md)。日常回顾没必要每次重推一遍。

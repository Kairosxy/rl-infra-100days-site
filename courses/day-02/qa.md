# Day 02 · 两个能检验理解的问题

## 题 1：一轮全部抽到 B，真实梯度就为零吗？

模型 `p(A)=0.25`、Reward(A)=1、Reward(B)=0。计算四次采样全部为 B 的概率；再计算单次 Score Function 梯度的两个取值、期望和方差。

**答案依据：** 全 B 概率 $0.75^4≈0.3164$；梯度取 0.75 或 0，期望 0.1875，方差 0.10546875。应区分有限样本现象与总体期望。

**追问：** 如果有效 Batch 足够大且样本近似独立，平均梯度估计的方差如何随样本数变化？什么时候不能直接写 $1/N$？

## 题 2：为什么平均 Reward 不一定是最好的 Baseline？

把常数 Baseline 记为 $b$，写出 A/B 两个动作的估计值，并找出使它们相等的 $b$；说明为什么不能直接把 `baseline=reward(current_action)` 作为通用写法。

**答案依据：** $g_b(A)=0.75(1-b)$、$g_b(B)=0.25b$，令二者相等得 $b=0.75$。当前动作 Reward 作为 Baseline 是动作相关的，会破坏不变期望的推导。

**追问：** 如果 Behavior Policy 抽 A 的概率为 0.9，而 Current Policy 为 0.25，仍然按 Current Score 无修正平均，期望是 0.1875 还是 0.675？为什么？

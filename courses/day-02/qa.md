# Day 02 · 明明有梯度，为什么这轮没更新？

假设模型只有 A/B 两种动作，`p(A)=0.25`，Reward(A)=1、Reward(B)=0。

**快速判断：** 连续四次都采到 B，是否说明理论上的 Policy Gradient 为零？

**不是。** 四次全 B 的概率约为 **31.64%**。本次采样可能全是零梯度，但真实的期望梯度为 `p(1-p)=0.1875`。一个 Batch 的结果和优化目标的期望不是一回事。

**能在十几秒内讲清吗？**

> REINFORCE 用采样动作估计期望梯度。估计是无偏的，不代表每次采样都有效；奖励稀疏时，同一策略的不同 Batch 可能差得很大。

**判断第二句：** “减去 Baseline 一定能降低方差，而且 Baseline 直接设为当前动作的 Reward 就行。”对不对？

不对。Baseline **可以**降低方差，但不是任意取值都有效；如果它依赖这一次采样的动作，就不能直接使用动作无关 Baseline 的证明。这个玩具例子里，最佳常数 Baseline 是 **0.75**，而平均 Reward 是 0.25。

# Day 04 · 看 Ratio 就能判断 Clip 的方向吗？

PPO 的 Clip Range 是 0.2。

**先判断，不需要写公式：**

- 一个好动作（Advantage = +2）的 Ratio 变成 **1.5**，还会继续因这个样本被鼓励吗？
- 一个差动作（Advantage = −2）的 Ratio 降到 **0.6**，还会继续因这个样本被压低吗？

**对照：这两种情况都进入平台。** 对应的 Clipped Surrogate 分别是 **2.4** 和 **−1.6**，在这些非边界位置，它们各自对 Ratio 的局部导数为零。

如果要用一句话解释：

> PPO Clip 并不是把所有 Ratio 超界的梯度都砍掉，而是阻止某个样本继续推动策略沿已经过大的有利方向变化。好动作在上界右侧进入平台，差动作在下界左侧进入平台。

**一个常见误判：** “Clip Range=0.2，所以新旧策略的 KL 肯定很小。”

不对。Clip 限制的是样本上的 Surrogate，不是对全词表、所有状态的 KL 硬约束。见 [完整反例与推导](lesson.md)。

这里不需要写一篇 PPO 小论文。能说清 Ratio 是“谁除以谁”、平台在哪侧、Clip 没保证什么，就可以继续。

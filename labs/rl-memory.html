① 固定模型/Batch，TP1/2/4 比较参数与激活峰值；② 固定输入输出长度分布，记录 KV Block 的实占与理论 KV 差异；③ 在相同总 GPU 下比较不同 TP×DP 的吞吐、P99 和权重同步时间。若 OOM：先区分常驻权重、训练激活、All-Gather 临时峰值、KV 和 CUDA Graph，再决定改 TP/PP/分片或 Batch。

注意：这里的 TP×PP×DP 仅为 Dense 模型的简化布局。EP 和 CP 不作为额外独立乘数；MoE 的 Expert 权重和路由、CP 的 KV 交换需单独建模。
